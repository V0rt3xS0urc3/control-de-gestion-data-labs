# 📊 Portafolio de Control de Gestión y Analítica de Datos

Repositorio dedicado a la práctica, proyectos y ejercicios de formación continua en Control de Gestión, Finanzas, Logística y Business Intelligence.

## 📂 Estructura del Repositorio
- 📈 **Excel y Finanzas:** Modelado de flujos, tablas dinámicas y automatización con IA.
- 📊 **Business Intelligence:** Dashboards y reportes en Power BI (DAX, Power Query).
- 🗄️ **Bases de Datos:** Consultas y extracción de datos con SQL.
- 🐍 **Análisis de Datos:** Scripts de limpieza y procesamiento masivo con Python (Pandas).
- 🏭 **Logística y ERP:** Ejercicios prácticos de gestión de materiales, compras y ventas (SAP MM/SD).

> *En constante actualización a medida que se completan las certificaciones.*
